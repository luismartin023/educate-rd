1 · Cadenas de caracteres

Una cadena es un arreglo de char terminado en '\0'. Toda función de string.h recorre hasta ese terminador; si falta, sigue leyendo memoria ajena.

REGLA DEL +1 — cadena de N caracteres → arreglo de al menos N+1 celdas (char nombre[51] para 50 letras). Con fgets suma una más para el '\n': char nombre[52].
Cómo se guarda "PUNTA"índices [0]P [1]U [2]N [3]T [4]A [5]\0 — 5 letras ocupan 6 celdas
Declaracioneschar c[6]="PUNTA" ok · char s[]="Hola" (5) ok · char mal[5]="PUNTA" ERROR (no cabe '\0' → printf imprime basura)

Lectura: fgets + strcspn (el patrón obligatorio)

char nombre[52];
printf("Nombre: ");
fgets(nombre, sizeof(nombre), stdin);       // lee línea completa, guarda el '\n'
nombre[strcspn(nombre, "\n")] = '\0';       // strcspn da la posición del '\n'

scanf("%s") corta en el primer espacio ("Luis Santana" → "Luis"). fgets lee la línea entera incluyendo el Enter. strcspn(s,"\n") devuelve la posición del '\n' (o la longitud si no hay) → seguro en ambos casos.

TRAMPA — un fgets que "se salta solo": un scanf anterior dejó el '\n' en el buffer y fgets lo lee como línea vacía. Fix: vaciar el buffer tras cada scanf.
void limpiarBuffer(void) {
    int c;
    while ((c = getchar()) != '\n' && c != EOF) { }
}
scanf("%d", &op); limpiarBuffer();   // ahora fgets sí espera al usuario

        s[i] = (char)tolower((unsigned char)s[i]);  // cast evita warning acentos

int codigoValido(char c[]) {                     // formato "AAA-NNN"
    if (strlen(c) != 7) return 0;                // longitud primero
    for (int i = 0; i < 3; i++) if (!isalpha((unsigned char)c[i])) return 0;
    if (c[3] != '-') return 0;
    for (int i = 4; i < 7; i++) if (!isdigit((unsigned char)c[i])) return 0;
    return 1;
}

2 · Vectores (arreglos 1D)

Índices válidos: 0 a n-1. Al pasarse a una función, C envía la dirección del primer elemento (referencia implícita) → la función modifica el arreglo original.

ARREGLO vs INT — el arreglo sí cambia dentro de la función; pero un int n viaja por valor. Si la función altera la cantidad, debe devolver el nuevo valor: n = registrar(nom, mat, notas, n);

Patrones que hay que saber escribir

int buscar(int arr[], int n, int val) {   // lineal: índice o -1
    for (int i = 0; i < n; i++)
        if (arr[i] == val) return i;
    return -1;                            // convención "no existe"
}
int maximo(int arr[], int n) {
    int max = arr[0];                     // NO 0: falla con negativos
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];
    return max;
}
float promedio(int arr[], int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) suma += arr[i];
    return (float)suma / n;               // cast ANTES de dividir
}
void doblar(int arr[], int n) {           // modifica el original
    for (int i = 0; i < n; i++) arr[i] *= 2;
}

Traza de búsqueda (ejercicio típico)

v[] = {15,42,7,28,56}, buscar 28: i=0→15 no, i=1→42 no, i=2→7 no, i=3→28 sí → return 3. Buscar 99 → recorre todo → return -1.

TRAMPA — i <= n accede a arr[n] (fuera del arreglo, off-by-one). Límite correcto: i < n.
TRAMPA — suma / n con ambos int = división entera que trunca antes de asignar al float. Fix: (float)suma / n.
TRAMPA — inicializar max = 0 rompe si todos los valores son negativos. Siempre max = arr[0].
PREDECIR SALIDA — doblar(v,3) sobre {1,2,3} → imprime 2 4 6 porque la función trabajó sobre el original.

Funciones y arreglos — resumen de reglas

  • Firma: void f(int arr[], int n) — siempre recibe también el tamaño (el arreglo no lo "sabe").
  • arr[] como parámetro = puntero disfrazado; sizeof(arr) dentro de la función NO da el tamaño real.
  • Modificar elementos dentro → visible fuera. Modificar n dentro → NO sale fuera (devuélvelo).
  • Matriz de cadenas: char nom[MAX][52] se pasa como char nom[][52] (la 2.ª dimensión es obligatoria).

4 · Ordenamiento

Los tres comparan de dos en dos; invertir el signo de la comparación invierte el orden (menor→mayor ↔ mayor→menor).

Inserción — como cartas en la mano

void insercion(int v[], int n) {
    for (int i = 1; i < n; i++) {
        int clave = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > clave) {
            v[j + 1] = v[j];   // correr a la derecha
            j--;
        }
        v[j + 1] = clave;      // insertar en el hueco
    }
}

Traza sobre {5,2,9,1,6}: i=1→{2,5,9,1,6} · i=2→igual · i=3→{1,2,5,9,6} · i=4→{1,2,5,6,9}.

Burbuja — el mayor sube al final

void burbuja(int v[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int huboCambio = 0;
        for (int j = 0; j < n - 1 - i; j++)
            if (v[j] > v[j + 1]) {
                int t = v[j]; v[j] = v[j+1];
                v[j + 1] = t; huboCambio = 1;
            }
        if (!huboCambio) break;  // ya ordenado
    }
}

Pasadas sobre {5,2,9,1,6}: p1→{2,5,1,6,9} · p2→{2,1,5,6,9} · p3→{1,2,5,6,9} · p4→sin cambios, se detiene.

Selección — mínimo al inicio

void seleccion(int v[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (v[j] < v[min]) min = j;
        if (min != i) {
            int t = v[i]; v[i] = v[min]; v[min] = t;
        }
    }
}
AlgoritmoMejor casoPromedioPeor casoEstableDetalle
Burbuja (con bandera)O(n)O(n²)O(n²)SíSin bandera, mejor caso también O(n²)
InserciónO(n)O(n²)O(n²)SíLa mejor si los datos ya están casi ordenados

Mejor caso = vector ya ordenado (inserción: 1 comparación por elemento). Peor caso = ordenado al revés. Inserción suele ganar a burbuja en la práctica: un desplazamiento = 1 asignación, un intercambio = 3.

Ordenar cadenas y arreglos paralelos

void ordenarNombres(char nom[][52], int n) {   // strcmp compara, strcpy mueve
    for (int i = 1; i < n; i++) {
        char clave[52]; strcpy(clave, nom[i]);
        int j = i - 1;
        while (j >= 0 && strcmp(nom[j], clave) > 0) {
            strcpy(nom[j + 1], nom[j]); j--;
        }
        strcpy(nom[j + 1], clave);
    }
}
ARREGLOS PARALELOS — nombre, precio y stock se mueven JUNTOS: al correr/insertar se repite el movimiento en cada arreglo (o se guarda toda la fila en variables clave y se reinserta completa). Es el patrón del sistema de estudiantes (nom + matrícula + notas).

int mostrarMenu(void) {                  // leer número + limpiar

float leerNota(int num) {                // validar rango con do-while
    float x;
    do {
        printf("Nota %d (0-100): ", num);
        if (scanf("%f", &x) != 1) x = -1;
        limpiarBuffer();
    } while (x < 0 || x > 100);
    return x;
}
