1 · Cadenas de caracteres string.h + ctype.h

ANALOGÍA — EL TREN CON BANDERA ROJA: En C no hay tipo string. Una palabra es un tren de casillas char que termina SIEMPRE en la bandera roja '\0'. Si no cabe el '\0', printf sigue leyendo basura ajena.
CASAS #104 vs #820 (== vs strcmp): En C, una cadena representa la dirección de su casa. nombre == "Maria" compara números de casa (falso siempre). strcmp(a, b) entra a las dos casas y compara letra a letra: devuelve 0 si son idénticas.
char nombre[52];

nombre[strcspn(nombre, "\n")] = '\0'; // borra el Enter

void limpiarBuffer(void) {            // tras cada scanf
    int c;
    while ((c = getchar()) != '\n' && c != EOF) { }

TRAMPA fgets + scanf: 1) fgets guarda el Enter como '\n', por eso "Maria\n" ≠ "Maria" y strcmp falla.
2) Si un fgets "se salta solo", un scanf anterior dejó el Enter en el teclado. Llama limpiarBuffer() tras scanf.
char n[5]="Pedro" → BASURA: "Pedro" tiene 5 letras pero necesita 6 celdas para el '\0'. Sin espacio para el terminador, printf lee basura después del nombre.

    if (strlen(c) != 7) return 0;
    for (int i = 0; i < 3; i++) if (!isalpha((unsigned char)c[i])) return 0;

2 · Vectores (arreglos 1D) índices 0 hasta n-1

ANALOGÍA — LLAVE DE LA CASA vs FOTOCOPIA: Pasar un arreglo int v[] a una función es prestarle la llave original: lo que cambie adentro queda cambiado en main. Pasar un int n es darle una fotocopia: si cambias n adentro, main no se entera — por eso hay que hacer return n + 1;

Los 3 patrones obligatorios

// 1. Búsqueda lineal: índice o -1
int buscar(int arr[], int n, int val) {
    for (int i = 0; i < n; i++)
        if (arr[i] == val) return i;
    return -1;
}
// 2. Máximo: arrancar con arr[0]
int maximo(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];
    return max;
}
// 3. Promedio real: cast antes de dividir
float promedio(int arr[], int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) suma += arr[i];
    return (float)suma / n;
}

TRAMPA — suma / n: int / int trunca los decimales antes de asignarse al float (84.33 → 84). Fix: (float)suma / n.
TRAMPA — i <= n: En int v[5] los índices son 0..4. Con i <= 5 accedes a v[5] (fuera de rango, off-by-one). Siempre i < n.
INICIALIZAR max = arr[0]: Si pones max = 0 y todos los valores son negativos, devuelve 0 en vez del mayor real.

TRAMPA — transpuesta con j = 0: Intercambia (0,1) con (1,0) y luego al llegar a la fila 1 vuelve a intercambiarlos → todo queda igual. Solución: j = i + 1.

4 · Ordenamiento y arreglos paralelos 3 algoritmos

PARA DUMMYS — EN UNA FRASE CADA UNO: Inserción: cartas en la mano (tomas una, corres mayores a la derecha, metes en el hueco). Burbuja: compara vecinos; el mayor flota al final en cada vuelta. Selección: busca al más pequeño de la fila y hace UN solo cambio por vuelta. Para mayor→menor solo cambia > por <.

Inserción

void insercion(int v[], int n) {
    for (int i = 1; i < n; i++) {
        int clave = v[i], j = i - 1;
        while (j >= 0 && v[j] > clave) {
            v[j + 1] = v[j]; j--;
        }
        v[j + 1] = clave;
    }
}

Traza {5,2,9,1,6}: i=1→{2,5,9,1,6} · i=2→igual · i=3→{1,2,5,9,6} · i=4→{1,2,5,6,9}.

Burbuja (con bandera)

void burbuja(int v[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int cambio = 0;
        for (int j = 0; j < n - 1 - i; j++)
            if (v[j] > v[j+1]) {
                int t=v[j]; v[j]=v[j+1];
                v[j+1]=t; cambio=1;
            }
        if (!cambio) break;
    }
}

Pasadas {5,2,9,1,6}: p1→{2,5,1,6,9} · p2→{2,1,5,6,9} · p3→{1,2,5,6,9} · p4→corta.

Selección

void seleccion(int v[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (v[j] < v[min]) min = j;
        if (min != i) {
            int t=v[i]; v[i]=v[min]; v[min]=t;
        }
    }
}

Ordenar cadenas (strcmp + strcpy)

void ordenarNombres(char nom[][52], int n) {
    for (int i = 1; i < n; i++) {
        char clave[52]; strcpy(clave, nom[i]);
        int j = i - 1;
        while (j >= 0 && strcmp(nom[j], clave) > 0) {
            strcpy(nom[j + 1], nom[j]); j--;
        }
        strcpy(nom[j + 1], clave);
    }
}

5 · Receta para los casos complejos + Respuestas relámpago

Cómo resolver los 2–4 casos largos del profe

1) PREDECIR SALIDA: Haz tablita en el margen (i | v[i] | condición | resultado). Nunca hagas bucles anidados en la mente. Recuerda: los arreglos sí guardan cambios en main.
2) CAZAR EL BUG (6 clásicos): ① == o = en texto · ② fgets dejó '\n' o saltó tras scanf · ③ i <= n · ④ int / int sin (float) · ⑤ transpuesta j=0 en vez de j=i+1 · ⑥ suma=0 fuera del for de filas.
3) JUSTIFICAR EN PAPEL: Di la causa en memoria + la línea que lo arregla. Ej: "Falla porque fgets guarda '\n'; se arregla con strcspn."

Respuestas relámpago (las 15 tarjetas del profe)

1. strlen("Hola")? → 4, cuenta sin contar el '\0'.
2. == en cadenas? → compara direcciones; usar strcmp(a,b)==0.
3. fgets extra? → mete '\n'; quitar con s[strcspn(s,"\n")]='\0'.
4. char n[5]="Pedro"? → falta celda para '\0' (regla +1 → [6]).
5. strstr no encuentra? → devuelve NULL (comparar != NULL).
6. Último índice de v[5]? → v[4] (N-1); v[5] es fuera.
7. Promedio sale entero? → int/int trunca; usar (float)suma/n.
8. Función cambia arr[0]? → sí modifica el original (referencia).
9. i <= n crashea? → off-by-one en arr[n]; usar i < n.
10. Inicializar max? → max = arr[0] (con 0 falla con negativos).
11. int m[3][4]? → 3 filas × 4 columnas (m[fila][col]).
12. Diagonal principal? → i == j, recorrer con m[i][i].
13. Sumar columna 2 (5×3)? → for(i=0;i<5;i++) s+=m[i][2];
14. Transpuesta usa j=i+1? → si j=0 cambia dos veces y queda igual.
15. ¿Cuál NO es estable? → Selección (siempre O(n²)). Burbuja e inserción sí son estables y O(n) si ya está ordenado.
