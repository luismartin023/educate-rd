1 Cadenas string.h + ctype.h

Una cadena en C es un arreglo de char que termina en '\0'. Todas las funciones de string.h dependen de ese terminador — si falta, leen memoria ajena.

Regla del +1. Una cadena de N caracteres necesita un arreglo de N+1 posiciones. Si lees con fgets, una más para que quepa el '\n': nombre de 50 → char nombre[52].
/* Leer cadenas BIEN — el patrón de siempre */
char nombre[52];
fgets(nombre, sizeof(nombre), stdin);        // lee línea completa + '\n'
nombre[strcspn(nombre, "\n")] = '\0';   // quita el Enter

/* Después de scanf, limpiar el buffer o fgets se "salta" */
void limpiarBuffer(void) {
    int c;
    while ((c = getchar()) != '\n' && c != EOF) { }
}
Un fgets que "se salta solo" = un scanf anterior dejó el '\n' en el buffer. Solución: limpiarBuffer() tras cada scanf.

2 Vectores arreglos 1D

Índices de 0 a n-1. Al pasar un arreglo a una función, C pasa la dirección del primer elemento: los cambios dentro de la función persisten fuera.

Pasar arreglo ≠ pasar variable. El arreglo se modifica dentro de la función (referencia implícita). Pero un int n se pasa por valor: si la función cambia la cantidad de elementos, debe devolver el nuevo valor: n = registrar(datos, n);
/* Búsqueda lineal — retorna índice o -1 (la convención) */
int buscar(int arr[], int n, int val) {
    for (int i = 0; i < n; i++)
        if (arr[i] == val) return i;
    return -1;
}

/* Máximo/mínimo: inicializar con arr[0], NO con 0
   (si todo es negativo, max=0 queda mal) */
int maximo(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];
    return max;
}
int / int = división entera que trunca. return suma / n; da entero aunque el tipo sea float. Corregir: return (float)suma / n;
for (i = 0; i <= n; i++) accede a arr[n] — fuera del arreglo (off-by-one). El límite correcto es i < n.
Si te piden "¿qué imprime?" con una función que modifica el arreglo: los cambios sí se ven en main porque el arreglo se pasó por referencia. doblar(v,3) sobre {1,2,3} → imprime 2 4 6.

m[FILAS][COLS] — el primer índice es siempre la fila. La confusión [i][j] vs [j][i] es el error más cobrado.

/* Transponer BIEN — cada par se toca una sola vez */
for (int i = 0; i < N; i++)
    for (int j = i + 1; j < N; j++) {
        int t = m[i][j]; m[i][j] = m[j][i]; m[j][i] = t;
    }

/* Sumar por filas — el acumulador se reinicia DENTRO del bucle externo */
for (int i = 0; i < F; i++) {
    int suma = 0;                       // aquí, no fuera
    for (int j = 0; j < C; j++) suma += m[i][j];
    printf("Fila %d: %d\n", i, suma);
}
Transponer con j = 0 intercambia cada par dos veces — la segunda deshace la primera y la matriz queda igual. Respuesta: j = i + 1.
Si todas las filas dan la misma suma: el suma = 0 está fuera del bucle externo y acumula entre filas.
Cadena dentro de matriz: char nombres[5][40] → fgets(nombres[2], 40, stdin) lee directo en la fila 2 (índice 2 = tercer nombre). Y con #define FILAS 3 los tamaños se cambian en un solo lugar.

4 Ordenamiento 3 algoritmos

Los tres comparan de dos en dos. Cambiar el signo de la comparación cambia de menor→mayor a mayor→menor.

Inserción

Como ordenar cartas en la mano: tomas la clave, corres a la derecha los mayores e insertas en el hueco.

for (int i = 1; i < n; i++) {
    int clave = v[i];
    int j = i - 1;
    while (j >= 0 && v[j] > clave) {
        v[j + 1] = v[j];
        j--;
    }
    v[j + 1] = clave;
}

Burbuja

Compara vecinos e intercambia; el mayor "sube" al final cada pasada. Con bandera huboCambio corta si ya está ordenado.

for (int i = 0; i < n - 1; i++) {
    int huboCambio = 0;
    for (int j = 0; j < n - 1 - i; j++)
        if (v[j] > v[j+1]) {
            int t = v[j]; v[j] = v[j+1];
            v[j+1] = t; huboCambio = 1;
        }
    if (!huboCambio) break;
}

Selección

Busca el mínimo de la parte que falta y lo pone al inicio: un solo intercambio por pasada.

for (int i = 0; i < n - 1; i++) {
    int min = i;
    for (int j = i + 1; j < n; j++)
        if (v[j] < v[min]) min = j;
    if (min != i) {
        int t = v[i]; v[i] = v[min]; v[min] = t;
    }
}
AlgoritmoMejor casoPromedioPeor casoEstableNota
Burbuja (con bandera)O(n)O(n²)O(n²)SíSin bandera, mejor caso también O(n²)
InserciónO(n)O(n²)O(n²)SíGana si los datos ya están casi ordenados
SelecciónO(n²)O(n²)O(n²)NoSiempre compara igual; pocos intercambios
Ordenar cadenas: mismo algoritmo, cambia la comparación (strcmp(a,b) > 0) y el movimiento (strcpy en vez de =). Datos paralelos (nombre + matrícula + notas): cada movimiento se repite en todos los arreglos — se mueven como una unidad.

M-01MatricesPredecir salida

M-02MatricesSelección
Sumar la columna 2 de una matriz de 4×3. ¿Cuál bucle es correcto?
Afor(j=0;j<3;j++) suma+=m[2][j];
Bfor(i=0;i<4;i++) suma+=m[i][2];
Cfor(i=0;i<3;i++) suma+=m[i][2];
Dfor(j=0;j<4;j++) suma+=m[j][j];
Columna fija = índice 2 fijo, recorres las 4 filas con i. La A suma una fila; la C deja fuera una fila; la D recorre la diagonal.
M-03MatricesError clásico
La transpuesta in-place con for(j=0; j<N; j++) deja la matriz igual. ¿Por qué?
Atmp no conserva el valor.
BIntercambia cada par dos veces: la segunda deshace la primera. Fix: j = i+1.
CFalta reiniciar tmp = 0.
DNo se puede transponer in-place.
Con j=0, el par (i,j) se intercambia y luego (j,i) lo devuelve. Con j=i+1 cada par se procesa una sola vez (triángulo superior).

Sí — arreglos se pasan por referencia implícita (dirección del primer elemento).
Vectores

Cuando i==n accede a arr[n], fuera del arreglo. Off-by-one: usar i < n.
Vectores

Matrices

3 filas × 4 columnas. Acceso: m[fila][columna].
Matrices
¿Qué condición marca la diagonal principal?
i == j — se recorre con m[i][i].
Matrices
¿Cómo sumas la columna 2 de una matriz 5×3?
Columna fija en 2, varía la fila: for(i=0;i<5;i++) suma+=m[i][2];
Matrices
¿Por qué la transpuesta usa j = i+1?
Con j=0 cada par se intercambia dos veces y queda igual. j=i+1 = solo triángulo superior.
Ordenamiento
¿Cuál de los 3 algoritmos no es estable?
Selección — siempre O(n²) incluso ya ordenado. Burbuja (con bandera) e inserción son estables y O(n) en mejor caso.
