Cadenas de caracteres

string.h + ctype.h

En C no existe el tipo string. Una cadena es simplemente un arreglo de letras que termina con una bandera invisible llamada '\0'.

Explicado para dummys · El tren con bandera roja

¿Por qué 5 letras necesitan 6 espacios?

Imagina un tren donde cada letra va en un vagón. Al final SIEMPRE debe ir un vagón extra con la bandera roja '\0' que significa "hasta aquí llegó la palabra". Si no dejas sitio para ese vagón extra, printf no sabe dónde parar y sigue leyendo basura de la memoria.

Explicado para dummys · El truco de las dos casas

¿Por qué nombre == "Maria" SIEMPRE falla?

En C, una cadena es la dirección de su casa en memoria (ejemplo: Casa #104 vs Casa #820). Aunque adentro de las dos casas viva la misma palabra "Maria":

Lo que hace == Compara los números de casa (#104 == #820). Como son casas distintas, dice FALSO aunque el texto sea igual.
Lo que hace strcmp(a, b) Entra a ambas casas y compara letra por letra. Si son iguales devuelve 0 ("cero diferencias").
Regla del +1 (de memoria) Para guardar máximo N letras necesitas char s[N+1]. Si lees con fgets, suma otra más para que quepa el Enter antes de borrarlo: nombre de 50 → char nombre[52];
Dos trampas clásicas de fgets y scanf 1) fgets guarda tu tecla Enter como '\n' dentro de la palabra, por eso "Maria\n" no es igual a "Maria". Se borra así: s[strcspn(s, "\n")] = '\0';
2) Si usas scanf("%d", &op) antes de un fgets, scanf deja el Enter botado en el teclado y fgets se lo traga y "se salta solo". Fix: llamar limpiarBuffer() después de cada scanf.
Lectura limpia + limpiarBuffer()
/* Leer una frase o nombre completo sin que quede el '\n' */
char nombre[52];
fgets(nombre, sizeof(nombre), stdin);
nombre[strcspn(nombre, "\n")] = '\0';

/* Vaciar la basura que deja scanf antes de leer texto */
void limpiarBuffer(void) {
    int c;
    while ((c = getchar()) != '\n' && c != EOF) { }
}

/* isalpha(c) letra | isdigit(c) 0-9 | isspace(c) espacio | toupper/tolower */
void aMayusculas(char s[]) {
    for (int i = 0; s[i] != '\0'; i++)
        s[i] = (char)toupper((unsigned char)s[i]); // cast evita warnings
}

/* Validar formato tipo "ISW-131" (3 letras, guion, 3 dígitos) */
int codigoValido(char c[]) {
    if (strlen(c) != 7) return 0;
    for (int i = 0; i < 3; i++) if (!isalpha((unsigned char)c[i])) return 0;
    if (c[3] != '-') return 0;
    for (int i = 4; i < 7; i++) if (!isdigit((unsigned char)c[i])) return 0;
    return 1;
}

Vectores (arreglos 1D)

0 hasta n-1

Una fila de casilleros numerados empezando en 0. Si tiene 5 casilleros, el último SIEMPRE es el 4 (nunca el 5).

Explicado para dummys · Fotocopia vs Llave de la casa

¿Por qué el arreglo sí cambia en main pero n no?

int arr[] → LLAVE ORIGINAL

C pasa la dirección real de tus casilleros. Si una función multiplica arr[i] *= 2, los números originales quedan cambiados al volver a main.

int n → FOTOCOPIA

C pasa una copia del número n. Si haces n++ adentro, el de main ni se entera — por eso hay que hacer return n + 1; y guardarlo con n = registrar(..., n);.

Prueba la trampa de suma / n: notas = 85, 90, 78 (suma = 253, n = 3)

Off-by-one (i <= n) Un arreglo de tamaño 5 llega hasta el índice 4. Escribir i <= 5 intenta abrir el casillero 5 que no existe → basura o crasheo. Siempre i < n.
Buscar máximo / buscar valor Máximo: arranca con max = arr[0] (si usas 0 y las notas fueran negativas, daría 0 mal).
Búsqueda lineal: devuelve el índice si aparece, y -1 si no existe.
Los 3 patrones de vectores que debes escribir sin pensar
/* 1. Búsqueda lineal: índice si está, -1 si no existe */
int buscar(int arr[], int n, int val) {
    for (int i = 0; i < n; i++)
        if (arr[i] == val) return i;
    return -1;
}

/* 2. Máximo: inicializar SIEMPRE con el primer elemento */
int maximo(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];
    return max;
}

/* 3. Promedio real: cast a (float) ANTES de dividir */
float promedio(int arr[], int n) {
    int suma = 0;
    for (int i = 0; i < n; i++) suma += arr[i];
    return (float)suma / n;
}

Inserción


for (int i = 1; i < n; i++) {
    int clave = v[i], j = i - 1;
    while (j >= 0 && v[j] > clave) {
        v[j + 1] = v[j];
        j--;
    }
    v[j + 1] = clave;
}

        

        

          
Burbuja (con bandera)


for (int i = 0; i < n - 1; i++) {
    int cambio = 0;
    for (int j = 0; j < n - 1 - i; j++)
        if (v[j] > v[j+1]) {
            int t=v[j]; v[j]=v[j+1];
            v[j+1]=t; cambio=1;
        }
    if (!cambio) break;
}

        

        

          
Selección


for (int i = 0; i < n - 1; i++) {
    int min = i;
    for (int j = i + 1; j < n; j++)
        if (v[j] < v[min]) min = j;
    if (min != i) {
        int t=v[i]; v[i]=v[min]; v[min]=t;
    }
}

M-02MatricesSelección

      
Quieres sumar la columna 2 de una matriz de 4×3 (4 filas, 3 columnas). ¿Cuál bucle es correcto?

      

        
Afor(j=0;j<3;j++) suma+=m[2][j];

        
Bfor(i=0;i<4;i++) suma+=m[i][2];

        
Cfor(i=0;i<3;i++) suma+=m[i][2];

        
Dfor(j=0;j<4;j++) suma+=m[j][j];

      

      
Columna fija = [2] clavado en el segundo corchete; recorres las 4 filas con i de 0 a 3.

    


    
M-03MatricesError clásico

      
La transpuesta in-place con for(j=0; j<N; j++) deja la matriz igual. ¿Por qué?

      

        
Atmp pierde el valor.

        
BIntercambia cada par dos veces y lo deshace. Fix: j = i + 1.

        
CFalta reiniciar tmp = 0.

        
DNo se puede transponer in-place.

      

      
Con j=0, cambias (i,j) y luego en (j,i) lo regresas. Con j=i+1 solo tocas el triángulo superior.
